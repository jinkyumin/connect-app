전체 아키텍처 설계

Expo + Supabase 풀스택 구조

기술 스택

📱 모바일 앱

Expo SDK 51 (React Native)
Expo Router — 파일 기반 내비게이션
NativeWind — Tailwind CSS 스타일링
Zustand — 전역 상태 관리
React Query — 서버 상태 캐싱

☁️ 백엔드 (Supabase)

PostgreSQL — 메인 DB
Supabase Auth — 이메일 인증
Supabase Storage — 이미지/영상
Supabase Realtime — 실시간 알림/DM
Edge Functions — 푸시 알림 (Expo Push)

🚀 배포

Expo EAS Build — iOS/Android 빌드
Expo EAS Submit — 앱스토어 배포
Supabase Cloud — 백엔드 호스팅
Expo OTA Update — 즉시 업데이트

앱 화면 구조 (Expo Router)
/(tabs) — 하단 탭 네비게이션
  ├── index — 홈 피드
  ├── search — 검색
  ├── new-post — 게시물 작성
  ├── activity — 알림
  └── profile — 내 프로필
/post/[id] — 게시물 상세 (스레드)
/profile/[id] — 타인 프로필
/messages — DM 목록
/messages/[id] — DM 대화방
/(auth) — 로그인/회원가입
