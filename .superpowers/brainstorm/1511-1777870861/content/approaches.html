Threads 클론 — 개발 접근 방식

React Native + Supabase 기반, 3가지 아키텍처 옵션

A

✅ 추천 — Expo + Supabase 풀스택

Expo SDK로 React Native 개발, Supabase로 DB/Auth/Storage/Realtime 모두 처리. 별도 백엔드 서버 없음.

장점

  • 가장 빠른 개발 속도
  • 인프라 관리 최소화
  • Supabase Realtime으로 푸시/DM 처리
  • Expo EAS로 앱 빌드/배포

단점

  • 복잡한 비즈니스 로직은 Supabase Edge Function 필요
  • Supabase 요금제 의존
B

React Native CLI + Supabase + Node.js API

순수 React Native CLI로 앱 개발, Supabase는 DB/Auth만 사용, 별도 Node.js Express API 서버 추가.

장점

  • 커스텀 비즈니스 로직 자유롭게 구현
  • 네이티브 모듈 완전 제어

단점

  • API 서버 별도 호스팅 필요
  • 개발/배포 복잡도 증가
  • 소규모 팀에는 오버엔지니어링
C

Expo + Supabase + Next.js 관리자 웹

A안에 추가로 Next.js 관리자 대시보드 포함. 앱은 Expo, 관리자는 웹으로 분리.

장점

  • 관리자가 웹에서 사용자/게시물 관리 가능
  • 모바일+웹 동시 운영

단점

  • 초기 범위가 커짐
  • 관리자 기능이 당장 필요한지 불확실
